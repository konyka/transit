Project Overview

Transit is a reimplementation of BlazingMQ (Bloomberg) in pure C99-C23.

Design Decisions

Key Decisions

  • Independent Protocol: Not compatible with BMQP. Clean binary protocol optimized for C.
  • Assembly Coroutines: Maximum performance, per-platform assembly context switch.
  • Zero External Dependencies: Self-contained, only optional deps (zlib for compression).
  • Work-Stealing Thread Pool: Better load distribution across cores.
